# 生和堂 APS 系统模块地图 (aps_module_map)

> 来源：《生和堂APS系统项目蓝图2.0（0721）.md》（项目权威需求文档）。本表用于用例编号 MOD 段、模块拆解与测试范围对齐；用户给定模块时以用户为准。

## 系统画像

| 项 | 值 |
|---|---|
| 系统名称 | 生和堂APS智能排程（高级计划排程系统 V2.0） |
| 行业 | 食品制造：龟苓膏、养生饮品、果汁系列 |
| 基地 | 江门总部、徐州基地、凭祥基地 + OEM 委外代工 |
| 外部对接 | 金蝶 ERP（客户/物料/BOM 主数据同步）、MES、WMS、BI |
| 核心链路 | 销售预测 → 主生产计划 → MRP 运算 → 制造排程 → 供应链协同 → 数据驾驶舱 |

## 食品行业特色约束（测试设计必须覆盖）

| 约束 | 系统对应功能 | 测试要点 |

| 食品安全 CCP | 工序管理-CCP 控制点标记 | 标记后工序参与排产校验 |
| 保质期管理 | 库存管理-批次管理 | 先进先出、批次追溯 |

| 得率波动 | 得率设置（按部门/产品） | 实际产出与理论投料比率边界 |
| 配方保密 | 角色管理-字段权限控制 | 数据权限/字段级越权测试 |
| 多基地协同 | 预测拆分-按基地分配 | 基地维度数据隔离 |
| 委外管理 | 委外产品维护、托工订单 | 委外单据状态流转 |
| 季节性波动 | 销售预测-季节项参数 | 季节参数边界 |

## 用例编号规则

`{SYS}_{MOD}_{4位序号}`，如 `APS_CPGY_QXGJ_0001`。同模块内序号连续；已发布资产的编号模式：

- `APS_CPGY_QXGJ_0001` — 产品工艺 / 清洗改机设置（一级取 CPGY）
- `APS_SCRZ_0001` — 生产资源设置 / 人员管理（一级取 SCRZ）

## 典型断言终态词汇表

列表页列名（清洗改机设置）：序号、规则名称、改机类型、原产品类型、目标产品类型、改机等级、适用工序、预计改机时长、状态、操作。

常见状态值：已审核 / 已确定 / 已锁定 / 已关单 / 待审 / 已驳回 / 启用 / 停用 / 已开工 / 已完工 / 延期。
